Lab 7: Kalman Filter

In this lab I implemented a Kalman Filter to improve the robot’s state estimation and allow faster and smoother motion.

1. Objective

The goal of this lab was to use a Kalman Filter to improve position and velocity estimation by combining a system model with noisy ToF measurements.

2. Step Response Data Collection

I collected step response data by driving the robot toward a wall at constant PWM and logging ToF, PWM, and time values using Bluetooth.

3. Velocity + Rise Time

Velocity was computed from ToF data. The rise time was measured as 0.868 s. I collected 13 datapoints over 1.229 s (~10.6 loops/sec).

4. System Modeling

I modeled the robot as a first-order system and estimated parameters using the step response. 

m * dv/dt = -d*v + u

Steady State:
d = u / v_ss

Time Constant:
tau = t_90 / 2.3

Momentum:
m = d * tau
A = [ 0    1
      0  -d/m ]

B = [ 0
      1/m ]

C = [ -1  0 ]
Ad = I + dt*A
Bd = dt*B

5. Kalman Filter (Python)

def kf(mu, sigma, u, y):
    mu_p = A.dot(mu) + B.dot(u)
    sigma_p = A.dot(sigma.dot(A.T)) + Sigma_u

    K = sigma_p.dot(C.T).dot(np.linalg.inv(
        C.dot(sigma_p).dot(C.T) + Sigma_z))

    mu = mu_p + K.dot(y - C.dot(mu_p))
    sigma = (np.eye(2) - K.dot(C)).dot(sigma_p)

    return mu, sigma

6. Discussion

The Kalman Filter improved estimation by combining model predictions with sensor data. This resulted in smoother motion and better velocity estimates compared to raw ToF or extrapolation.
