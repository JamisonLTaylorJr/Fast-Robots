Lab 10: Grid Localization with Bayes Filter

In this lab I implemented a probabilistic localization algorithm using odometry and sensor data.

1. Understanding Grid Localization

The goal of this lab was to estimate the robot’s pose (x, y, θ) using a Bayes Filter. Instead of tracking an exact position, the robot exists in a discretized grid where each cell represents a possible pose and stores a probability.

The grid used in this lab had dimensions (12, 9, 18), and the belief across all cells must always sum to 1.

2. Bayes Filter Overview

The Bayes Filter works in two steps:

  • Prediction: Uses odometry to estimate where the robot moved
  • Update: Uses sensor data to correct the estimate

The prediction step increases uncertainty, while the update step reduces it.

3. Computing Control Input

To implement the motion model, I computed control inputs in the form (rotation1, translation, rotation2) using odometry data. 

def compute_control(cur_pose, prev_pose):
    cur_x, cur_y, cur_theta = cur_pose
    prev_x, prev_y, prev_theta = prev_pose

    dx = cur_x - prev_x
    dy = cur_y - prev_y

    heading = np.degrees(np.arctan2(dy, dx))
    delta_rot_1 = mapper.normalize_angle(heading - prev_theta)

    delta_trans = np.sqrt(dx**2 + dy**2)

    delta_rot_2 = mapper.normalize_angle(cur_theta - prev_theta - delta_rot_1)

    return delta_rot_1, delta_trans, delta_rot_2

This breaks motion into two rotations and one translation, while also normalizing angles so they stay within [-180, 180).

4. Motion Model

def odom_motion_model(cur_pose, prev_pose, u):
    d_rot1, d_trans, d_rot2 = compute_control(cur_pose, prev_pose)

    p1 = loc.gaussian(d_rot1, u[0], loc.odom_rot_sigma)
    p2 = loc.gaussian(d_trans, u[1], loc.odom_trans_sigma)
    p3 = loc.gaussian(d_rot2, u[2], loc.odom_rot_sigma)

    return p1 * p2 * p3

Each motion component is modeled using a Gaussian distribution, and the total transition probability is the product of all three components.

5. Prediction Step

The prediction step updates the belief based on motion. 

threshold = 1e-4
valid_prev = np.argwhere(loc.bel >= threshold)

for px, py, pt in valid_prev:
    prev_state = mapper.from_map(px, py, pt)
    weight = loc.bel[px, py, pt]

    probs = np.array([
        odom_motion_model(mapper.from_map(cx, cy, ct), prev_state, u)
        for (cx, cy, ct) in flat_states
    ])

    probs = probs.reshape(loc.bel.shape)
    loc.bel_bar += weight * probs

I ignored very low probability states (< 1e-4) to improve performance, which made a huge difference in runtime.

6. Sensor Model

def sensor_model(obs):
    return [
        loc.gaussian(exp_val, meas_val, loc.sensor_sigma)
        for exp_val, meas_val in zip(obs, loc.obs_range_data)
    ]

9. Discussion
