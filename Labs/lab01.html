Lab 1: The Artemis board and Bluetooth

Prelab 1A: Hook Up Artemis Board

Before starting the BLE portion, I verified that my Artemis could reliably upload code, print to Serial, and read onboard sensors using the built-in example sketches.

1) Connect + Select Board/Port
  • Connected the Artemis to my computer via USB and confirmed a stable physical connection.
  • In Arduino IDE, selected Board: RedBoard Artemis Nano and the correct Port.
  • At "Basic Examples" I will be doing multiple board checks to make sure my board works as it should..
2) Basic Examples
Blink
File → Examples → 01.Basics → Blink
The first check is to use the Blink example. Here I was able to make the boards LED blink of an on with intervals.
Serial Example
File → Examples → Apollo3 → Example4_Serial
The Serial example was able to print to the Serial Monitor without any issues and I was also able to type characters in the Serial Monator and have it printed back to me.
Temperature Sensor
File → Examples → Apollo3 → Example2_analogRead
The next test was using analog read and identifying the tempurature sensor component of the board. Even though this boards temp. sensor was not the greatest, I was able to use a heat source (my finger) to see a general change in the temperature readings over time.
Microphone (PDM)
File → Examples → PDM → Example1_MicrophoneOutput
Here I was testing the boards microphon sensor. I ran the code and spoke into the microphone and saw the measured frequency (Hz) content change.
For 5000 Level Students: Musical Note Tuner
Here I was able to use the microphone and its paired example to detect musical notes and display them in the Serial Monitor. I searched up the frequencies of the notes C, E, and G in the 6th octave and played each note to see if the board could detect them correctly. It was able to detect each note with no major issues.

Prelab 1B: Preparing my Computer

Lab 1B focuses on establishing Bluetooth communication between your computer and the Artemis board. Using Python commands sent from a Jupyter notebook, the computer will communicate with an Artemis board programmed and displayed in Arduino. This lab also sets up a reusable framework for transmitting data from the Artemis back to the computer over Bluetooth, which will used in later labs.
