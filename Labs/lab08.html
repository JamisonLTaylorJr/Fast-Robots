Lab 8: Stunts (Drift)

In this lab I combined the Kalman Filter and IMU-based PID control to perform a high-speed drift maneuver.

1. Objective

The goal of this lab was to combine all previous control systems to perform a fast stunt. I chose Task B (Drift), where the robot drives quickly toward a wall, detects when it is within approximately 3 ft, performs a 180° turn, and then drives away.

2. Approach and Planning

This lab felt like a combination of Lab 6 and Lab 7. I used the Kalman Filter to estimate distance to the wall and the IMU-based PID controller to control the robot’s orientation.

To organize the behavior, I implemented a simple state machine that switches between driving forward, drifting (turning), and driving away.

3. Drift State Machine

I used a state variable drift_state to control the behavior of the robot: 

int drift_state = 0;
// 0 = drive toward wall
// 1 = drift (turn 180)
// 2 = drive away
// 3 = stop

This allowed me to clearly separate each phase of the stunt and switch control strategies at the correct time.

4. Driving Toward the Wall

In the first phase, the robot drives quickly toward the wall using the Kalman Filter estimate of distance instead of raw ToF data. 

error1P_drive = distance1_est - targetDistance1;

if (error1P_drive > 0 && drift_state == 0) {
  drive_backward(70);
}
else if (error1P_drive < 0 && drift_state == 0){
  drift_state = 1;
}

Once the estimated distance drops below the threshold (~3 ft), the system transitions into the drift phase.

5. Drift (180° Turn)

During the drift phase, the robot switches to orientation control using the IMU. The yaw angle is extracted from the DMP and compared to a 180° target. 

error1P_ori = Gyro_yaw - targetOrientation1;

A PID controller determines the turning direction and magnitude. I used a deadband of about 2 degrees to stop the turn cleanly. 

if (fabs(error1P_ori) <= deadband_ori) {
  drift_state = 2;
}
else {
  drift_right(...) or drift_left(...)
}

I implemented custom drift functions to create a faster turning motion by driving the motors in opposite directions with asymmetric speeds.

6. Driving Away

After completing the turn, the robot drives away from the wall at a constant speed to complete the stunt. 

else if (drift_state == 2){
  drive_backward(70);
}

This final motion makes the stunt visually clear and demonstrates that the robot successfully reoriented itself.

8. Discussion

This lab demonstrated how multiple control systems can be combined into a single behavior. The Kalman Filter helped provide a smoother distance estimate, while the IMU-based PID controller enabled accurate turning.

One challenge was tuning the transition between driving and drifting. Small changes in the distance threshold or PID gains could significantly affect performance.

Overall, this lab tied together everything from previous labs and showed how model-based estimation and control can be used for fast and dynamic motion.
